## Описание программы

Graph Navigator — консольное приложение на Python для работы с графами.

Программа поддерживает:

- создание графов;
- добавление и удаление вершин;
- добавление и удаление рёбер;
- ориентированные графы;
- неориентированные графы;
- взвешенные графы;
- алгоритм BFS (обход в ширину);
- алгоритм DFS (обход в глубину);
- алгоритм Дейкстры для поиска кратчайшего пути;
- сохранение графа в JSON;
- загрузку графа из JSON.

В проекте используются:
- ООП;
- инкапсуляция;
- наследование;
- полиморфизм;
- паттерн Factory.

## Возможные тесты

### Проверка BFS

```python
BFS.traverse(graph, "A")
```

Ожидаемый результат:

```text
A -> B -> C -> D -> E
```

---

### Проверка DFS

```python
DFS.traverse(graph, "A")
```

Ожидаемый результат:

```text
A -> B -> D -> E -> C
```

---

### Проверка Дейкстры

```python
Dijkstra.find_shortest_paths(graph, "A")
```

Ожидаемый результат:

```python
{
    'A': 0,
    'B': 4,
    'C': 2,
    'D': 3,
    'E': 6
}
```
